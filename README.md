# MediLink - Healthcare Service Platform

A modern web application for managing medicine orders and deliveries, built with React, TypeScript, and Vite.

## Features

- User Authentication
- Medicine Search and Management
- Order Tracking System
- Real-time Status Updates
- Responsive Design
- Dark/Light Theme Support

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router DOM
- React Query

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/medilink.git
```

2. Install dependencies
```bash
cd medilink
npm install
```

3. Start the development server
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/         # Main application pages
├── hooks/         # Custom React hooks
└── lib/           # Utility functions
```
